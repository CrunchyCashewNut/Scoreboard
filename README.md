# 🏀 Basketball Scoreboard

A simple and clean basketball scoreboard built using **HTML, CSS, and JavaScript**.  
This project helped me practise DOM manipulation, custom fonts, flexbox layout, and interactive UI design.


## 🚀 Live Demo  
👉 [View the scoreboard](https://crunchycashewnut.github.io/Scoreboard/) : https://crunchycashewnut.github.io/Scoreboard/


## 🎯 Features
- Update scores for **Home** and **Guest** teams  
- Buttons for adding **+1**, **+2**, and **+3** points  
- Custom digital-style font for the display  
- Responsive layout with Flexbox  
- Minimal, modern, card-style UI
